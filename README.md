# ☕ Exercícios de Herança e Encapsulamento em Java

Este repositório contém a resolução de exercícios práticos focados em **Programação Orientada a Objetos (POO)** em Java, abordando os conceitos fundamentais de **Herança** e **Encapsulamento** (uso de modificadores `private`, métodos `getters` e `setters`).
